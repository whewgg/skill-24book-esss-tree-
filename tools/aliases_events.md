# 事典通称 ↔ 正史用词对照表
#
# 为什么需要这张表：
#   问"乌台诗案"时，正史里**根本不出现**这个词——宋史苏轼传写的是「逮赴台狱」。
#   模型拿通称去检索必然零命中，于是反复换词（乌台诗案→乌台→诗案→…），
#   每次全库再扫一遍，几分钟就这么耗掉；最后还容易顺手编一个卷次（如"宋史·列传第一"）交差。
#   本表让 rag.py / q.py 在通称零命中时**自动改按史文用词检索**，并在输出头部标注改写过程。
#
# 格式：每行一组，全角竖线分隔。
#   第一个词 = 后世／今人通称（**可能不在本库任何文件里出现**，这是正常的）
#   其后各词 = 本库（正史原文）实际用词，**必须是已在本库实测存在的词**
#
# 维护：
#   新增一行后**无需重跑任何脚本**（rag.py / q.py 实时读取）。
#   但右端每个词上线前必须实测：python tools\rag.py <词> --count
#   实测为 0 的写法禁止写进来（会退化成"换了词还是零命中"）。
#   右端若是已实测词的**超串**（如已测「禄山」→可写「安禄山」）可放行，因为超串命中必蕴含子串命中。
#   ⚠ 右端词**宁精勿泛**：只写"本案会用到、且尽量专有"的词。泛化的司法名词（如「御史狱」「台狱」）
#   会命中几十个无关案件，把真正的史料淹没在噪音里。乌台诗案只留「逮赴台狱」（本案专用）＋
#   「御史狱」（能捞到王安礼传"苏轼下御史狱"），删掉了对本案零增量的「台狱」（苏轼∩台狱＝0 段）。
#
# 已知本库无载（勿写成右端词）：苗刘（苗刘之变）、释兵权、北狩、二帝
