# 案件总表 —— 08-案件索引的数据源（手工维护）
#
# 用途：为「某案出处在哪」建立检索入口。tools\build_case_index.py 读本表 → 生成 08-案件索引.md；
#       生成时逐案回扫语料，出处（书名/卷次/路径/行号/摘句）全部由脚本实测得出，**不采信本表**。
#
# 行格式（全角竖线分隔，7 列，缺一不可）：
#   案件名｜别名｜时代｜类型｜当事人｜检索词｜按语
#   · 案件名 = 今人常用名（可不在本库出现）
#   · 别名   = 其他通称，多者用·分隔；**通称未必见于本库**（如「胡蓝之狱」本库零命中，属正常）
#   · 时代   = 「朝代·细分」，朝代须为：秦/汉/晋/南北朝/隋/唐/宋/元/明/清（决定分节）
#   · 类型   = 大狱/刑案/文字狱/党争/政变/民变/兵变/战事/宫廷案
#   · 当事人 = 主要人物，多者用·分隔（用于检索选词参考，不参与生成）
#   · 检索词 = **必须是本库实测存在的史文用词**，多者用/分隔（「X案」式通称多半零命中，勿写）
#              同形假阳性用 `词!排除串1!排除串2` 剔除：命中行含排除串即不算该词命中
#              （实测「杨乃武」头号命中是晋书骈句「殷杨乃武」，「哭庙」三处全是礼制用语）
#   · 按语   = 编者提示（非史文），引用仍须回原文；含零命中通称、易混词、别名提示
#
# 维护纪律（与 aliases_events.md 同规）：
#   ① 检索词上线前实测：python tools\rag.py <词> --count
#   ② 零命中的通称不要写进「检索词」（写进「别名」并在按语说明），并到 tools\aliases_events.md 登记改写
#   ③ 改本文件后重跑：python tools\build_case_index.py（或 tools\make_indexes.py 一键重建）
