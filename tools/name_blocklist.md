# 非人名屏蔽表（生成 02-人物字号索引 与 03-人物出现索引 时剔除）
#
# 为什么需要这张表：
#   02 的「X，字Y」句式匹配会把**介词/连词/动词短语**当成姓名（「乃宣敕告之」「食邑于贾地」），
#   05 的列传篇名里还有**类传题名**（「宦者一」「东夷」「后妃二」）与**合传简称**
#   （「侯张薛」＝侯君集、张亮、薛万均的合传）——它们都过得了姓氏白名单，却不是人物。
#   这类词条混进 03 后，检索会给出"某人出现在 N 卷"的假线索，模型照着答就是错的。
#
# 格式：每行一条。
#   名级  `词条｜理由`              —— 该名的**全部**条目剔除
#   行级  `词条｜字：某｜理由`      —— 只剔 (名=词条, 字=某) 这一对（同名下真假混杂时用）
#
# 维护纪律：
#   1. 新增词条**必须附语料证据**，且要用
#      `python tools\rag.py locate <词条> --limit 3` 实际看过上下文再写——
#      凭语感删"像假名"的词条会误删真实人物（本库真有 万亨／万琛／万观／于朋举／习凿齿）。
#   2. 改完重跑 `build_name_index.py` → `build_person_mentions.py`（02/03 同时生效）。
#   3. 类传题名（宦者/东夷/后妃这类**整类**）不需要登记在这里——
#      `build_person_mentions.py` 的 `CATEGORY_TITLES` 规则会自动拦；这里只登记
#      规则拦不住的**逐条误配**与**合传简称**。
